# Zent Backend

Backend API for Zent, a gamified personal finance application designed
to help students manage their finances and build better financial habits.

## Features

- User authentication and authorisation
- Income and expense tracking
- Budget management
- Savings goals
- XP and gamification system
- Protected API routes

## Tech Stack

- Node.js
- Express.js
- MySQL
- JavaScript

## Architecture

The application follows a modular architecture with separate:

- Controllers
- Models
- Routers
- Middleware
- Validators
